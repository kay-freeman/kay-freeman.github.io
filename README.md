## Featured Systems

### [Incident Signal](https://github.com/kay-freeman/incident-signal)

A configurable Python incident-detection system that analyzes support-ticket activity, separates distinct issue clusters, assigns explainable severity levels, and produces operational reports.

**Demonstrates:** systems analysis, business rules, incident operations, input validation, automated testing, technical documentation, and CI/CD.

### [DriftWatch](https://github.com/kay-freeman/Drift-Watch)

A TypeScript configuration-auditing system that detects discrepancies between infrastructure policies and live state, records audit history, and supports controlled remediation.

**Demonstrates:** policy-as-code, configuration management, risk controls, schema validation, historical reporting, and automation.

### [SyncForge](https://github.com/kay-freeman/syncforge)

A production-pattern webhook ingestion service designed for reliable event processing with idempotency, persistent lifecycle tracking, background jobs, rate limiting, and structured logging.

**Demonstrates:** API design, event-driven architecture, distributed processing, data reliability, observability, and containerized infrastructure.
