# Kay Freeman — Systems Command Center

A static, GitHub Pages-ready portfolio for Kay Freeman, positioning her work across technical operations, business systems, AI, and automation.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish on GitHub Pages

Create a public repository named `kay-freeman.github.io`, add these files to the repository root, and push to `main`. GitHub Pages will publish the site at `https://kay-freeman.github.io/`.
